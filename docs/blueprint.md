# **App Name**: MediQuery

## Core Features:

- Medicine Search and Display: Implement a search bar with autocomplete functionality for medicines. The search should filter by category or symptom, providing quick suggestions as the user types. Display a concise list of matching medicines with essential details.
- Voice Input: Allow users to input queries via voice in English or Tamil. Integrate with the Google Web Speech API to convert speech to text, which will then be used for medicine searches or chatbot interactions. Enable storing of voice preferences in settings.
- AI Chatbot: Integrate a basic NLP chatbot using a Hugging Face NLP model or rule-based logic to answer medical queries. The chatbot will act as a tool to provide information based on a user's query about medicine.

## Style Guidelines:

- Primary color: White or light grey for a clean interface.
- Secondary color: A calming blue (#3498db) to convey trust and reliability.
- Accent: Green (#2ecc71) to highlight important information and CTAs.
- Clear and readable font for medical information.
- Clean and intuitive layout optimized for mobile devices.
- Use recognizable icons for categories and functions.
